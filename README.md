# **API для управления библиотекой**

- REST API предоставляет возможности для управления книгами,
авторами и пользователями, а также позволяет отслеживать выдачу книг пользователям. 
- API реализован на Django и Django Rest Framework (DRF).
- Для хранения данных используется база данных PostgreSQL.
- Для контейнеризации используется Docker и Docker Compose.
- Автогенерируемая документация API реализована по стандарту OpenAPI.
---

##  Цель проекта

Повысить эффективность в работе библиотеки - уйти от привычных бумажных карточек
с записями о пользователях и выдаче книг, облегчить жизнь персоналу и ускорить его работу.

---

## Основной функционал

Управление API осуществляется ролями: **сотрудник** (библиотекарь) и **пользователь** (владелец).

### 1. Управление книгами: модель ```Book```

- Создание, редактирование и удаление книг доступно только сотруднику.
- Получение списка всех книг доступно аутентифицированным пользователям.
- Поиск книг по различным критериям (название, автор, жанр и т.д.) реализовано через django-filters.

### 2. Управление авторами: модель ```Author```

- Создание, редактирование и удаление авторов доступно только сотруднику.
- Получение списка всех авторов доступно аутентифицированным пользователям с фильтрацией.

### 3. Управление пользователями: модель ```User```

- Регистрация доступна каждому, аутентификация и авторизация пользователей по JWT-токену.
- Получение информации о пользователях доступно только сотруднику, 
а пользователь увидит лишь свои данные. Всех активных пользователей с фильтрацией видит только сотрудник.
- Удаление и редактирование пользователя доступно владельцу и сотруднику при условии, что взятых книг нет.

### 4. Выдача книг:  модель ```BookIssue```

- Запись информации о выдаче книги доступна пользователю, сотруднику доступны все существующие записи с фильтрацией.
- Отслеживание статуса возврата книги - доступность книги к выдаче регулируется флагом в модели выдачи
>**"Книга возвращается - становится доступна"**

>Простыми словами - права доступа реализованы таким же образом, как и в реальной библиотеке, где выдают бумажные варианты книг.
Пользователю нужно лишь зарегистрироваться и выбрать книгу - остальное за библиотекарем, который реализует выдачу.

## Установка и запуск на локальном компьютере

- Клонируйте репозиторий
```
git clone https://github.com/AzatAlfredovich/skypro_diplom.git
```
- Установите зависимости
```
pip install -r requirements.txt
```
- Создайте файл .env по шаблону .env.sample. и заполните его, учитывая имя сервиса в docker-compose.
- Запустите контейнеры через Docker Compose
```
docker-compose up -d --build
```
